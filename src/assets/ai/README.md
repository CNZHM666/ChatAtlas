# AI platform icons

Selected unmodified SVG marks from [Lobe Icons](https://github.com/lobehub/lobe-icons), npm package `@lobehub/icons-static-svg` version **1.97.0** (MIT). Assets are bundled locally; no remote icon requests or runtime package dependency. Brand marks identify conversation sources.

The upstream copyright and MIT license are retained in [LICENSE.txt](LICENSE.txt).

Included marks: OpenAI (ChatGPT), Claude, Gemini, DeepSeek, Kimi, Doubao, Qwen, Grok, Yuanbao, ChatGLM, Zhipu (GLM), Perplexity, Copilot and Mistral. Monochrome marks use CSS masks to follow the current theme; colored marks retain their original fills.
