# ChatAtlas 数据与隐私

**简体中文** · [English](en/PRIVACY.md)

版本 0.1.1，更新于 2026-10-24。对话、来源版本、项目、笔记、收藏、阅读记录、分析缓存和 API 配置保存在当前浏览器。公开版本不提供共享 AI 服务或知识库云同步。导出文件由你主动选择并在本机读取。Claude、Gemini、DeepSeek、豆包、Kimi、通义千问（含 Qwen 国际站）在获得浏览器网站权限后默认采集当前已加载的对话到本地。设置中可逐个平台暂停或恢复；暂停后停止采集，保留已保存材料。采集不调用模型或上传到 ChatAtlas 服务器。

## 何时离开设备

- 网页扫描、同步或捕获访问 ChatGPT，读取对应材料；导出文件由本机解析。
- 主动执行整理、问答、演进等 AI 任务时，所需资料与任务直接发送至你选择的服务商。
- **项目上下文精炼**仅发送当前预览和任务，包括主动加入的收藏与预览编辑；不会额外重读整库。展开精炼面板不发送请求。
- 可选语义增强和向量建立可能向你配置的服务商发送相关内容，入口在高级设置。
- 主动连接测试可能发送小型请求并计费。
- 普通阅读、本地关键词查找、项目上下文本地打包与编辑不调用模型。

所选服务商如何处理请求取决于其政策和你的配置。ChatAtlas 不通过自有服务器转发 BYOK 密钥或生成请求。

## 密钥与缓存

API 密钥保存在当前浏览器，不包含在知识备份中；本地浏览器存储不是独立密钥保险库。妥善管理设备与浏览器配置，切勿将配置文件、备份或密钥上传公开仓库。

成功分析和精炼结果可保存在本机缓存，以减少重复成本。用量诊断保留请求阶段、模型、耗时和 Token 等元数据；完整诊断导出可能包含私有项目元信息，提交反馈前需要脱敏。未知计费不表示免费，取消也不保证服务商未收费。

## 扩展权限

固定站点权限覆盖 ChatGPT 以及上述六类 AI 网页和其已列出的域名别名；安装或更新时由浏览器授予权限。自定义 API 地址仍按需申请权限。`storage` 保存本地配置，`tabs` / `scripting` 连接支持的 AI 页面与工作区，`alarms` 维护同步目录，`sidePanel` 支持浏览器原生侧栏。普通网页不因打开侧栏而成为已导入 AI 对话。历史导入仅在用户选中并导入时逐条打开后台标签页读取已加载正文；用户激活该标签页后不会自动关闭它。不会自动批量打开账号所有历史。

主动插入仅填写输入框、不发送；原输入已有草稿时保留，并使用复制退路。

## 备份与反馈

备份包含私人对话正文和个人记录，只保存到你选择的位置；恢复会替换本机知识数据，操作前确认。不包含 API 密钥。卸载、清理浏览器或更换扩展身份前先备份。

反馈请提供版本、模型、错误码和复现步骤；删除密钥、账号信息和私人正文，优先使用虚构材料。本地历史诊断、真实上下文示例、部署文件和机器专用指令不属于公开源码包。
