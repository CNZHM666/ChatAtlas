# 项目导出

**简体中文** · [English](en/CONTEXT.md)

项目工具栏的「导出」统一提供总览和 Wiki 文件导出，原有「使用项目上下文」、交接窗口和侧栏项目上下文入口已移除。

1. 打开项目，点击右上角「导出」。
2. 选择项目总览、全部或指定 Wiki 章节；仅当已有历史事项或演进时，才在「以前保存的记录」中按需选择。
3. 默认导出 Markdown，也可选择 HTML、纯文本或 JSON。HTML 可通过浏览器打印为 PDF。
4. 按需勾选来源摘录，点击导出。

Markdown 或纯文本可作为附件提供给其他 AI。支持的六类 AI 网页已提供原生侧栏与输入框适配试用，网页采集在浏览器授权后自动运行；网页历史与正文限已加载内容，不保证账号完整历史。

导出不调用模型，也不改写正文。建议、计划、用户报告和实际验证的区别应保留在已保存内容中；附有来源不代表每条解释已确认正确。导出前先保存个人修改。

不再提供独立的任务打包和 AI 精炼入口。历史收藏、快照和备份数据保留，不会因入口移除而自动删除。文档路径保留以兼容已有链接。
