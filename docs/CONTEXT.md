# 项目导出

**简体中文** · [English](en/CONTEXT.md)

项目工作台与原生侧边栏的「导出」统一提供总览和 Wiki 文件导出，并共用**精简（Brief）**、**开发（Handoff）**和**审计（Audit）**三种 Markdown 预设；原有「使用项目上下文」、交接窗口和侧栏项目上下文入口已移除。

1. 在工作台或侧边栏打开项目，点击「导出」。
2. 选择导出模式：精简（适合快速阅读与轻交接）、开发（适合交给队友、Codex 或 Claude Code，含技术规则、已定决定与紧凑原话定位）或审计（含完整总览、归属标注、原话摘录与核对信息）。在工作台可进一步勾选项目总览、指定 Wiki 章节或历史记录。
3. 默认导出 Markdown（支持一键复制或下载 `.md`），工作台也支持 HTML、纯文本或 JSON。HTML 可通过浏览器打印为 PDF。
4. 按需调整来源摘录选项，点击复制或导出。

Markdown 或纯文本可作为附件提供给其他 AI。支持的六类 AI 网页已提供原生侧栏与输入框适配试用，网页采集在浏览器授权后自动运行；网页历史与正文限已加载内容，不保证账号完整历史。

导出不调用模型，也不改写正文。建议、计划、用户报告和实际验证的区别应保留在已保存内容中；附有来源不代表每条解释已确认正确。导出前先保存个人修改。

不再提供独立的任务打包和 AI 精炼入口。历史收藏、快照和备份数据保留，不会因入口移除而自动删除。文档路径保留以兼容已有链接。
