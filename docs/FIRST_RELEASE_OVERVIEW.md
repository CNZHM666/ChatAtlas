# ChatAtlas 首版范围

**简体中文** · [English](en/FIRST_RELEASE_OVERVIEW.md)

版本：0.1.3 Early Preview。以下为可用入口和实际限制，不是全模型实测承诺。

## 支持平台

对话文件导入支持 ChatGPT、Claude、Gemini（Google Takeout JSON）和 DeepSeek 的官方导出，以及其他 AI 的 Markdown／JSON 对话记录。Claude、Gemini、DeepSeek、豆包、Kimi、通义千问（含 Qwen 国际站）提供网页适配试用：浏览器授予网站权限后默认自动运行，可在设置中暂停或恢复；支持原生侧栏、本地查找、项目关联、已加载消息同步、原文定位和输入框填入。网页历史导入读取已加载标题并逐条保存已加载正文；仅保存当前已加载的消息，不保证完整历史。ChatGPT 保留专用历史列表与正文同步。新增适配尚未经登录网站逐一验收；BYOK 模型服务商与对话来源平台相互独立。

现有上下文可以复制／导出，再由用户手动带到其他 AI。配置不同 BYOK 模型服务商用于整理，也不等同于支持对应网站的对话导入或侧栏。

## 已开放能力

| 状态 | 能力 |
| --- | --- |
| 主路径 | ChatGPT ZIP/JSON 与网页导入、本地关键词查找、原文连续阅读、范围确认、总览/Wiki 整理、预览保存、个人编辑、来源回看 |
| 主路径 | 原生侧栏「查找／上下文」、搜索结果定位与 Reader 阅读、本地准备上下文、同页收藏、复制与保护草稿的主动插入 |
| 主路径 | 本地打包已保存总览/Wiki，按任务和章节选择；可选 AI 精炼，候选采用与还原 |
| 主路径 | 备份恢复、成功分析复用、有界恢复、请求与用量记录 |
| 主路径 | 单个或多个对话整理为总览与 Wiki，核对、编辑、按需更新和导出 Markdown／可打印 PDF 的 HTML |
| 历史兼容 | 独立项目问答、事项与演进工作区已移除；旧数据保留，历史事项和演进可选导出 |
| 高级可选 | 语义检索、向量配置及主动建索引 |
| 暂未开放 | 架构 AI 生成；已有内容继续可读与维护 |
| 未提供 | 知识库云同步、共享付费服务、其他平台完整原生采集与插入 |

一次整理最多 24 条对话；首次完整分析长材料仍需输入和输出 Token。原文引用与程序校验不等于事实证明，个人标记处理不代表实际代码完成。

第一版更适合邀请用户验证「自己的材料能否顺畅导入 → 整理 → 查阅 → 交给新 AI」这条路径。自动化模拟通过后，真实模型质量、耗时、费用及 ChatGPT 页面兼容性仍需按[发布清单](RELEASE_CHECKLIST.md)记录。
