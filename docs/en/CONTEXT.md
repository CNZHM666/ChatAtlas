# Project export

[简体中文](../CONTEXT.md) · **English**

Use **Export** in the project toolbar for the saved overview and Wiki. Separate project-context, handoff and sidebar-context entries have been removed.

1. Open a project and select **Export**.
2. Choose the overview and all or selected Wiki chapters. Previously saved matters/evolution appear only when present, inside Previously saved records.
3. Markdown is the default; HTML, plain text and JSON are also available. HTML can be printed to PDF in the browser.
4. Optionally include source excerpts, then export.

Markdown or text files can be provided to another AI as attachments. The six Beta website adapters support native panels and composer insertion and run automatically after browser permission. Website inventory and bodies are limited to loaded content, without guaranteed full history.

Export makes no model call and does not rewrite content. Preserve distinctions between proposals, plans, user reports and actual verification. Source references do not certify every interpretation. Save personal edits before exporting.

Separate task packing and AI-refinement entries are retired. Existing collections, snapshots and backup data are retained. This documentation path remains compatible with existing links.
