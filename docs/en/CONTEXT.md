# Project export

[简体中文](../CONTEXT.md) · **English**

Use **Export** in either the Project Workbench or the native sidebar for the saved overview and Wiki, sharing the **Brief**, **Handoff**, and **Audit** Markdown presets. Separate project-context, handoff and sidebar-context entries have been removed.

1. Open a project in the Workbench or sidebar and select **Export**.
2. Pick an export mode: **Brief** (clean reading & quick context), **Handoff** (technical specs, confirmed decisions, and compact locators for teammates, Codex, or Claude Code), or **Audit** (full overview, attribution marks, excerpts, and check details). In the Workbench, you can also select specific Wiki chapters or previously saved records.
3. Markdown is the default (copy or download `.md`); HTML, plain text and JSON are also available in the Workbench. HTML can be printed to PDF in the browser.
4. Adjust source excerpt options if needed, then copy or export.

Markdown or text files can be provided to another AI as attachments. The six Beta website adapters support native panels and composer insertion and run automatically after browser permission. Website inventory and bodies are limited to loaded content, without guaranteed full history.

Export makes no model call and does not rewrite content. Preserve distinctions between proposals, plans, user reports and actual verification. Source references do not certify every interpretation. Save personal edits before exporting.

Separate task packing and AI-refinement entries are retired. Existing collections, snapshots and backup data are retained. This documentation path remains compatible with existing links.
